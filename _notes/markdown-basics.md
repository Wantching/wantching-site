> 这是一篇示例笔记，也可以留作写作时的速查表。

## 标题和段落

文章的大标题由文件顶部的 `title` 决定，正文从二级标题开始即可：

```markdown
## 一节的标题

这是一个自然段。

空一行，再写下一段。
```

## 强调和列表

```markdown
这里有一个 **重点**。

- 第一项
- 第二项
```

## 链接和图片

```markdown
[回到首页](/)

![图片说明](/assets/images/example.jpg)
```

图片要先放进项目的 `assets/images/` 文件夹；上面的 `example.jpg` 只是文件名示例，替换成你自己的图片名后再用。

## 代码

短代码用一对反引号包住，例如 `git status`。多行代码放在三个反引号之间，可以在开头写上语言名：

````markdown
```python
print("Hello, Wantching!")
```
````

暂时记住这些写法，就足够写大多数文章和笔记了。
